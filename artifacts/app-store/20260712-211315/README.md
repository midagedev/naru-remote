# App Store screenshots — 2026-07-12

These are the exact English (U.S.) screenshot sets prepared for Naru Remote
1.0.0 (build 1).

- `final-iphone/`: five 1284×2778 iPhone screenshots.
- `final-ipad/`: five 2752×2064 iPad landscape screenshots.

The order in each directory is the intended App Store order: Connections,
live session, multilingual Compose, Direct special keys, then Diagnostics on
iPhone or Trackpad cursor on iPad.

The screenshots were captured from deterministic DEBUG-only XCUITest fixtures.
All files passed PNG decode, dimension, sRGB, and opacity checks plus manual
visual review. Raw captures and `.xcresult` bundles remain local working
artifacts and are ignored by this directory's `.gitignore`.
